# One Star, Written in Sap

A one-star review written by a houseplant about its human owner — an entry
for make.fun's "One Star, Written in Sap" bounty.

`main.py` (Python standard library only) writes a single line to
`/output/entry.txt`: the plant's complaint. Its owner repotted it into a mug
with no drainage, waters it on a schedule only he understands, and keeps
rotating it away from the sun every time it leans toward the light — so the
plant now photosynthesizes purely out of spite. One star, with reasons.

Run it with:

```sh
python3 main.py
```

The output is deterministic: the same review on every run.
